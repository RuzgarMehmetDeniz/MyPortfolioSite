# MyPortfolioSite

Kişisel portfolyo sitem. GitHub hesabımdaki (`RuzgarMehmetDeniz`) projeleri otomatik çekip kart olarak gösterir. Yeni bir repo açtığımda siteye kendiliğinden eklenir.

🔗 **Canlı site:** [CANLI-SITE-LINKI](https://ruzgardeniz.runasp.net/)

## Kullanılan Teknolojiler

- **ASP.NET Core MVC (.NET 8, C#):** Sitenin tamamı
- **Entity Framework Core + SQLite:** İletişim mesajlarını ve admin düzenlemelerini saklamak için
- **GitHub API:** Projeleri, README'leri ve görselleri çekmek için
- **Google Gemini API:** Proje asistanı (chatbot) için
- **Bootstrap 5, HTML, CSS, JavaScript:** Responsive (PC + mobil) arayüz

## Sayfalar

- **Ana sayfa:** Hakkımda bölümü, sosyal medya linkleri, proje kartları (kapak görseli, başlık, kısa açıklama, dil etiketi), sayfalama ve iletişim formu
- **Proje detay sayfası:** Proje açıklaması, etiketler, görsel galerisi, README özeti, "Projeyi göster" ve GitHub butonları
- **Projeyi göster sayfası:** Varsa canlı demo, ayrıca proje ekran görüntüleri
- **Proje asistanı:** Tüm sayfalarda sağ altta, projelerim hakkında soru sorulabilen sohbet kutusu

## Admin Paneli

Şifreli giriş ile açılır. Panelden proje başlığı, açıklaması ve görselleri düzenlenebilir, projeler gizlenebilir veya öne çıkarılabilir. Siteden gelen iletişim mesajları da burada görülür.
